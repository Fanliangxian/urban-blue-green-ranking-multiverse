## Reproducibility boundary

The package does not claim that the full analysis can run without external inputs. Third-party boundary, land-cover, population, water and terrain data must be obtained from their original providers. ArcGIS Pro/ArcPy is required for the frozen residual spatial-dependence/Conley step. Google Earth Engine assets must be created in the user's own project. These dependencies and the expected file layout are documented in `DATA.md` and `docs/REPRODUCIBILITY.md`.
